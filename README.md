# SGTU Schedule (Расписание СГТУ)

**SGTU Schedule** — это мобильное приложение и компаньон для часов на базе Wear OS, предназначенное для удобного просмотра расписания занятий Саратовского государственного технического университета имени Гагарина Ю.А. (СГТУ).

Проект разделён на два основных модуля: мобильное приложение (`:mobile`) и приложение для смарт-часов (`:wear`), обеспечивая бесшовную синхронизацию данных между устройствами.

---

## 🚀 Основные возможности

### 📱 Мобильное приложение (`:mobile`)
* **Парсинг расписания:** Автоматическое скачивание и парсинг официальных расписаний СГТУ в формате PDF.
* **Выбор группы:** Удобный интерфейс выбора учебной группы.
* **Просмотр расписания:** Современный интерфейс на Jetpack Compose для просмотра занятий по дням недели.
* **Уведомления и будильники:** Напоминания перед началом занятий с использованием `AlarmManager`.
* **Фоновое обновление:** Периодическое автоматическое обновление расписания в фоновом режиме с помощью `WorkManager`.
* **Синхронизация с часами:** Автоматическая отправка актуального расписания на сопряжённое Wear OS устройство через Google Wearable Data Layer API.

### ⌚ Приложение для Wear OS (`:wear`)
* **Просмотр на ходу:** Оптимизированный интерфейс для быстрого просмотра расписания текущего и следующих дней прямо с запястья.
* **Плитка:** Собственная плитка быстрого доступа (Tile) для мгновенной проверки ближайшего занятия без необходимости открывать приложение.
* **Автономность:** Получает данные от смартфона и сохраняет их локально для быстрого доступа.

## 🛠 Технологический стек

* **Язык программирования:** Kotlin (с использованием современных подходов и сопрограмм / Coroutines)
* **UI-фреймворк:** Jetpack Compose (для смартфона) и Compose для Wear OS (для часов)
* **Архитектура:** MVVM-подобная структура с разделением на слои данных (Repositories) и интерфейса
* **Фоновые задачи:** Jetpack WorkManager для планирования фонового парсинга и обновления плиток
* **Синхронизация:** Google Play Services Wearable Data Layer API
* **Работа с PDF:** Скачивание и извлечение текста из документов расписания

---

## 📂 Структура проекта

* [`:mobile`](./mobile) — Модуль Android-приложения для смартфонов. Содержит логику парсинга PDF, планирования уведомлений и основной UI.
* [`:wear`](./wear) — Модуль приложения для носимых устройств (Wear OS), включая сервисы плиток (Tiles) и усложнений (Complications).
